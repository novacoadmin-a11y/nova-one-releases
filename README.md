# NOVA ONE for Mac and Windows

Installers and updates for NOVA ONE by NOVA Enterprise Limited. This repository holds releases only, no source code.

**Download the latest version**
- Windows: [NOVA-ONE-windows-setup.exe](https://github.com/novacoadmin-a11y/nova-one-releases/releases/latest/download/NOVA-ONE-windows-setup.exe)
- Mac (Apple silicon and Intel): [NOVA-ONE-mac.dmg](https://github.com/novacoadmin-a11y/nova-one-releases/releases/latest/download/NOVA-ONE-mac.dmg)

Installed apps update themselves: when a new version is out, NOVA ONE shows "Update and restart" in its sidebar.
Every update is signed by NOVA, and the app refuses one that is not.
